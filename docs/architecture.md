# ICES v2 Architecture

## 4-Layer Framework

### Layer 1: Agent Physics
- Households, merchants, farmers
- Geography (grid-based)
- Ecology (water, soil, forest, energy)
- Networks (village, merchant, scholarly)

### Layer 2: Economic Mechanisms
- Bimetallic (Dinar/Dirham) vs Fiat
- Commodity Reserve Department (CRD)
- Islamic contracts (Murabaha, Salam, Ijara)

### Layer 3: Institutions
- Zakat (redistribution)
- Waqf (perpetual endowments)
- Hisba (market supervision)
- Shura (governance)

### Layer 4: Metrics
- Wealth Index
- Trust Index
- Justice Index
- Ecological Index
- Spiritual Capital
